# Routines are per-Gym lists of Exercise Configurations with set counts

The user wanted workout templates, named Routines. A Routine belongs to one Gym and stores an ordered list of that Gym's Exercise Configurations, each with a set count, but no weights, reps or notes: starting it creates empty set slots, and the existing "Last workout" references supply last time's values, as for Repeat and for added exercises. We chose per-Gym Configurations over Gym-independent Exercise Variations because a Configuration already captures the equipment and machine used there, so starting a Routine stays one tap with no equipment questions (see ADR 0001), and we chose set counts over stored targets so a Routine never goes stale as loads progress.

Routines sit beside Repeat this workout rather than replacing it: Repeat copies one Completed Workout, while a Routine is an edited plan that can also be saved from one. Workouts do not refer to their Routine, so deleting a Routine is a real delete; deleting a never-used Gym or Configuration removes it from Routines, and archived Configurations and Variations stay listed but are skipped when the Routine starts, as in Repeat. The Routines screen adds exercises from the Gym's existing Configurations rather than the full exercise picker, which is built around the Active Workout; an exercise new to a Gym is first added to a workout there.
