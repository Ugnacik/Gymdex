# Triage Labels

The skills speak in terms of five canonical triage roles. In this repo they are inline tags at the end of a `docs/backlog.md` item, e.g. `3. Add X. [ready-for-agent]`.

| Label in mattpocock/skills | Tag in backlog.md | Meaning                                  |
| -------------------------- | ----------------- | ---------------------------------------- |
| `needs-triage`             | `needs-triage`    | Maintainer needs to evaluate this item (also the default when untagged) |
| `needs-info`               | `needs-info`      | Waiting on the developer for more information |
| `ready-for-agent`          | `ready-for-agent` | Fully specified, ready for an AFK agent  |
| `ready-for-human`          | `ready-for-human` | Requires human implementation            |
| `wontfix`                  | `wontfix`         | Will not be actioned                     |
